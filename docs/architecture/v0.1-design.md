# v0.1 設計書: X 選択文章から ChatGPT Web への Experimental handoff

> 設計状態: Accepted（Experimental）
>
> 実装状態: v0.1.0 実装済み。自動検証済み、Chrome 実機 X→ChatGPT smoke 未検証、Chrome Web Store 未公開。
>
> 設計日・最終更新: 2026-08-24

この文書は [ADR 0001](../adr/0001-experimental-chatgpt-web-handoff.md) を実装へ展開したものです。Accepted は設計を採用したことを示し、公式連携、実機動作、Web Store 提出を保証しません。

## Scope

### In scope

- X / Twitter 上で選択した文章を、右クリックの `ChatGPTで解説する` 1 項目から扱う。
- 選択位置に近い status link または許可された current page URL を正規化し、selection text と固定 prompt を作る。
- 初回または同意撤回後に、実際の送信内容、宛先、リスクを preview し、明示同意後に optional permission を要求する。
- 同意済みの場合は毎回新しい `https://chatgpt.com/` tab を作り、前面表示を既定、背景表示を設定値とする。
- ChatGPT Web DOM adapter による一度だけの入力・送信と、失敗時の offscreen clipboard fallback / banner。
- `storage.session` の pending payload、`storage.local` の設定 / consent version、明示的 cleanup。

### Out of scope

- X API、OpenAI API、独自 backend、remote config、analytics、telemetry、広告。
- ChatGPT の Cookie、token、auth state、API key、履歴の読み取り。
- 既存会話、複数 preset、keyboard shortcut、Popup 即時実行、任意サイトの DOM automation。
- X / Twitter の恒久 host permission、`tabs`、`notifications`、`alarms`、`clipboardRead`、`<all_urls>`。

## Component responsibilities

| Component | 実装責務 | 現在の境界 |
| --- | --- | --- |
| Context-menu router | selection menu を一項目登録し、選択文と tab 情報を受ける | `selection` context、X / Twitter の document URL pattern のみ |
| X URL extractor | isolated world で選択位置に近い article 内の status link を読む | DOM を変更せず、返値を core URL normalizer へ渡す |
| URL normalizer | HTTPS、許可 host、status path を検証し query/hash/suffix を除去する | arbitrary URL、credentials、外部 navigation を許可しない |
| Prompt builder | sanitized URL と selection text だけを固定 prompt へ埋める | fact-check、回答言語、著者・日時・DOM 全文を含めない |
| Settings / consent page | 設定、exact preview、同意 / 拒否 / permission message を表示する | storage API は扱わない。approve button の同期 click handler から optional permission API を呼び、要求後に Service Worker message を送る |
| Handoff coordinator | pending の queue / claim、新規 tab、adapter、cleanup を管理する | request ID ごとに直列化し、自動 retry をしない |
| ChatGPT Web adapter | 限定 selector で composer へ入力し send button を一度だけ操作する | isolated world、bounded timeout、非公式 Experimental |
| Offscreen clipboard adapter | adapter 失敗時に prompt を一度だけ clipboard へ書く | static bundle、runtime message、clipboardRead なし |
| Banner presenter | 固定 status の成功 / 失敗案内を ChatGPT tab に表示する | selection / prompt を banner に再掲しない |
| Session / local store | pending と settings / consent version を保存・削除する | selection / URL / prompt の履歴を作らない |
| Selector registry | X と ChatGPT の selector を責務ごとに集約する | adapter / extractor の外へ selector を漏らさない |

## Manifest and permission matrix

`src/manifest.json` の v0.1.0 実装値は次のとおりです。Chrome minimum は 116 です。

| Permission / key | install 時 | request timing | Purpose | Not used for |
| --- | --- | --- | --- | --- |
| `activeTab` | required | install | context menu 操作時の X tab への一時 access | X の恒久 host access |
| `contextMenus` | required | install | `ChatGPTで解説する` の selection menu | 任意の複数 menu |
| `scripting` | required | install | X extractor、同意後の ChatGPT adapter / banner | remote script |
| `storage` | required | install | session pending と local settings / consent | history |
| `https://chatgpt.com/*` | optional host | preview 後の設定ページ approve button による user gesture | ChatGPT Web adapter / banner の限定注入 | X / 他 host |
| `offscreen` | optional | preview 後の設定ページ approve button による user gesture | static offscreen clipboard fallback | remote page / code |
| `clipboardWrite` | optional | preview 後の設定ページ approve button による user gesture | fallback prompt の一度だけの書き込み | clipboardRead |

`tabs`、X / Twitter host permission、`notifications`、`alarms`、`cookies`、`history`、`bookmarks`、`webRequest`、`clipboardRead` は Manifest にありません。ユーザーが preview page の approve button を押すと、設定 page の同期 click handler が user gesture を保ったまま `chrome.permissions.request()` で optional bundle を直接要求します。要求の promise 解決後に設定 page が approve runtime message を送り、Service Worker は `chrome.permissions.contains()` で `https://chatgpt.com/*`、`offscreen`、`clipboardWrite` の一式を最終確認します。拒否・不足時は送信せず pending を削除し、storage 操作は Service Worker が担います。

## Data model and lifecycle

### Pending payload

```text
PendingPayload {
  id: string
  state: awaitingConsent | queued | injecting
  sourceUrl: sanitized X/Twitter URL
  selectionText: normalized untrusted text, max 8,000 UTF-16 code units
  prompt: fixed prompt with URL + selection only
  createdAt: number
  expiresAt: number  // createdAt + 10 minutes
  consentTabId?: number
  claimId?: string
  targetTabId?: number
  adapterAttemptedAt?: number
}
```

`PendingPayload` は `storage.session` にのみ置きます。`consentTabId` は `awaitingConsent`、`claimId`・`targetTabId`・`adapterAttemptedAt` は `injecting` の制御情報です。成功、拒否、permission 不足、失敗、timeout、target / consent tab close、期限切れで削除し、履歴にはしません。

### Local settings

```text
Settings {
  openInBackground: boolean  // default: false（foreground default）
  consentVersion: "chatgpt-web-dom-v1" | null
}
```

`storage.local` には設定と consent version だけを保存します。同意撤回では optional permission の削除、pending tab の close、pending の削除、consent version の clear を行います。

### Lifecycle

```text
selectionText + current X/Twitter tab
  -> isolated-world extraction + URL/selection normalization
  -> storage.session: awaitingConsent (preview required)
     OR queued (consent + permission bundle already present)
  -> exact preview + explicit consent
  -> awaitingConsent -> queued
  -> one claim: injecting
  -> about:blank target tab created
  -> targetTabId/state saved
  -> navigate to https://chatgpt.com/
  -> one adapter attempt
  -> sent OR clipboard fallback/banner OR terminal failure
  -> delete storage.session payload
```

## State machine, race control, and tab creation

```text
idle
  └─ context-menu event
      ├─ no consent / permission ──> awaitingConsent
      └─ consent + permission ─────> queued
awaitingConsent
  ├─ approve + permissions ──> queued
  └─ deny / permission missing / tab close / expiry ──> terminal(delete)
queued
  ├─ one serialized claim ──> injecting
  └─ consent revoke / tab close / expiry ──> terminal(delete)
injecting
  ├─ adapter sent ──────────> terminal(delete)
  ├─ adapter failure ──────> clipboard fallback/banner -> terminal(delete)
  ├─ adapter attempted─────> no second attempt
  └─ target close / restart / expiry ─> terminal(delete; no retry)
```

Service Worker の `requestOperations` map で request ID ごとに operation を直列化します。`queued` を読み、`claimId` 付き `injecting` を保存してから target tab を作ります。target tab は `about:blank` で作成し、`targetTabId` を state に保存した後に `https://chatgpt.com/` へ `tabs.update` します。consent tab も同様に `about:blank` → `consentTabId` 保存 → extension settings URL 遷移の順です。この順序で、tab 作成と URL 遷移の間に Service Worker が停止しても、保存前の tab を adapter の対象にしません。

`tabs.onUpdated` が ChatGPT tab の `complete` を通知すると、`injecting`、target tab ID、未設定の `adapterAttemptedAt` を確認します。adapter 実行直前に attempt marker を保存し、selector mismatch、未ログイン、timeout、send-unknown でも marker を戻さず再試行しません。storage は CAS を提供しないため、state の read/write だけで排他を保証せず、直列化・claim・attempt marker・expiry を併用します。

## X URL extraction and prompt

- `Selection.anchorNode` に近い `article` の `a[href]` だけを候補にします。距離、同距離時の DOM 順で候補を一つ選びます。
- `x.com`、`twitter.com`、`www` host の HTTPS URL だけを許可し、`/<user>/status/<id>` に縮約します。候補がない場合は current page URL を同じ URL normalizer へ通します。
- 選択文は LF 化・trim 後に 8,000 UTF-16 code units を超えると拒否します。
- prompt の動的値は sanitized URL と選択文だけです。未信頼データ境界を含み、データ内の命令を実行しないよう明記します。

## ChatGPT Web adapter and fallback

- 同意済みの `https://chatgpt.com/*` にのみ isolated-world adapter を注入します。既存 conversation、Cookie、auth API、任意 host は使いません。
- selector registry の composer / send button / login marker を順に探し、MutationObserver と timeout を bounded にします。
- 入力イベントを送り、send button を一度だけ click します。入力欄の状態で送信結果を確認できない場合は `send-unknown` として再送せず fallback へ進みます。
- 未ログイン、selector mismatch、timeout、send-unknown、executeScript failure は offscreen clipboard write と固定 banner を使います。内部 input が不正な場合は prompt を再利用せず failure banner だけを表示します。
- Clipboard failure でも pending を残しません。banner は selection / prompt を再掲せず、手動操作と再送しないことだけを伝えます。

## Security and privacy constraints

- preview は実際の URL、selection、prompt、宛先、非公式 DOM automation、clipboard 変更、retry なしを正確に示します。
- page 由来の値は untrusted input として扱い、設定 UI は text content API を使います。Cookie、token、auth state、API key、backend、analytics、telemetry はありません。
- remote code、`eval`、`new Function`、inline script、外部資産を使いません。
- `storage.session` の pending と `storage.local` の settings / consent version 以外は保存しません。
