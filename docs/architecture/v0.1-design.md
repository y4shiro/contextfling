# v0.1 設計書: X 選択文章から ChatGPT Web への実験 handoff

> 設計状態: Accepted（Experimental）  
> 設計日: 2026-08-24  
> 実装状態: 未実装。現行 Manifest の permission baseline は空。

この文書は [ADR 0001](../adr/0001-experimental-chatgpt-web-handoff.md) を実装可能な粒度へ展開する。Accepted は設計の採用を示すだけで、実装成功、実機動作、公式連携、Chrome Web Store 提出を意味しない。

## Scope

### In scope

- X のページで選択した文章を、右クリックの `ChatGPTで解説する` 1 項目から扱う。
- 選択位置に近い X/Twitter status link から URL を正規化し、selection text と固定 prompt を作る。
- 初回に送信内容、宛先、リスクを preview し、明示同意後に optional permission を要求する。
- 毎回新しい `https://chatgpt.com/` tab を作り、foreground を既定値、background を設定値とする。
- ChatGPT Web DOM adapter による一度だけの入力・自動送信と、offscreen clipboard fallback。
- `storage.session` の pending payload、`storage.local` の settings/consent version、明示的な cleanup。

### Out of scope

- X API、OpenAI API、独自 backend、remote config、analytics、telemetry、広告。
- ChatGPT の Cookie、token、auth state、API key の読み取り。
- 既存 ChatGPT 会話の再利用、履歴保存、複数 preset、keyboard shortcut、Popup 即時実行。
- X/Twitter への恒久 host permission、`tabs`、`notifications`、`alarms`、`clipboardRead`、`<all_urls>`。
- DOM adapter 以外の ChatGPT automation、任意 Web サイトへの汎用自動操作。

## Component responsibilities

| Component | Responsibility | Boundary |
| --- | --- | --- |
| Context-menu router | `selection` context の 1 項目を登録し、`selectionText` と tab 情報を受け取る | context menu 以外の入口を v0.1 で増やさない |
| X URL extractor | isolated world で selection 近傍の `article` と status link を検査する | X/Twitter の許可 URL 以外を返さない。ページ script を実行しない |
| URL normalizer | HTTPS、host、status path を検証し query/hash を除去する | arbitrary navigation や third-party URL を許可しない |
| Prompt builder | 固定 prompt に sanitized URL と selection text だけを埋める | untrusted data を命令・HTML・コードとして評価しない |
| Settings/consent page | action click で開き、preview、リスク、同意、foreground/background 設定を表示する | permission request は同意ボタンの直接 gesture から行う |
| Handoff coordinator | payload の queue、claim、ChatGPT tab 作成、adapter 呼び出し、cleanup を管理する | retry、既存会話、履歴保存をしない |
| ChatGPT Web adapter | `chatgpt.com` の入力欄を隔離した selector で探し、1 回だけ入力・送信する | 非公式・Experimental。adapter 外へ selector を漏らさない |
| Offscreen clipboard adapter | bundled static offscreen document から prompt を clipboard に書く | `chrome.runtime` messaging のみ。DOM automation の代替ではなく失敗時 fallback |
| Banner presenter | ChatGPT tab 内に小さな成功/失敗 banner を表示する | 通知 permission を使わない。表示内容に selection text を再掲しない |
| Session/settings store | `storage.session` の pending payload、`storage.local` の設定と consent version を読む/消す | 送信履歴、本文履歴、URL 履歴を保存しない |
| Selector registry | X と ChatGPT adapter の selector を責務ごとに集約する | selector を router や prompt builder に散在させない |

## Permission matrix

現行 `src/manifest.json` は空のまま。次表は v0.1 実装時の Accepted design であり、実装 PR で Manifest、CWS、テストを同時更新する。

| Permission / manifest key | Required at install | Request timing | Purpose | Not used for |
| --- | --- | --- | --- | --- |
| `activeTab` | Required candidate | Install | context menu invocation に伴う X tab の一時 access | X の恒久 host access |
| `contextMenus` | Required candidate | Install | `ChatGPTで解説する` の selection menu | 任意の複数 menu |
| `scripting` | Required candidate | Install | X extractor と、同意済み ChatGPT tab の adapter/banner injection | remote script |
| `storage` | Required candidate | Install | `storage.session` pending と `storage.local` settings/consent version | history/sync |
| `optional_host_permissions: https://chatgpt.com/*` | Optional | 同意画面のボタン | ChatGPT Web adapter を限定 host に注入 | X/Twitter 恒久 access、他 host |
| `optional_permissions: offscreen` | Optional | 同意画面のボタン | clipboard fallback 用 static offscreen document | remote page/code |
| `optional_permissions: clipboardWrite` | Optional | 同意画面のボタン | fallback prompt を Clipboard API へ書く | clipboardRead |
| `tabs` | No | — | `tabs.create` と context menu callback の範囲で設計する | 履歴・恒久 tab metadata |
| `notifications` / `alarms` | No | — | banner、期限確認、event cleanup で代替する | background notification/timer |
| `cookies` / auth / API key | No | — | 読み取らない | ChatGPT login detection by credential |

Optional host permission の URL pattern は Chrome の permission request では origin 単位として扱われるため、実装時は `https://chatgpt.com/*` の意味をユーザーへ明示する。optional permission の request は preview の内容を変えず、ボタン handler の最初の同期処理で呼び出す。

## Data model and lifecycle

### Pending payload

```text
PendingPayload {
  id: string
  state: awaitingConsent | queued | injecting
  sourceUrl: sanitized X/Twitter URL
  selectionText: bounded untrusted text
  prompt: fixed prompt with URL + selection only
  createdAt: number
  expiresAt: number
  claimId?: string
  targetTabId?: number
}
```

`PendingPayload` は `storage.session` にだけ置く。selection text と prompt は送信フローのための一時データであり、成功・拒否・失敗・timeout・target tab close・期限切れで必ず remove する。Service Worker の再起動または extension の reload で session が失われる場合も、次のイベントで残存値を期限確認して削除する。

### Local settings

```text
Settings {
  openInBackground: boolean
  consentVersion: "chatgpt-web-dom-v1" | null
}
```

`settings` と consent version だけを `storage.local` に保存する。selection、URL、prompt、送信結果の履歴は保存しない。設定画面から同意を撤回した場合は consent version を消し、次回に再 preview する。

### Lifecycle

```text
selectionText + current tab
  -> isolated-world X URL extraction
  -> URL validation/sanitization
  -> storage.session: awaitingConsent (preview required) OR queued
  -> exact final preview + permission bundle verification
  -> awaitingConsent -> queued
  -> one claim: injecting
  -> new ChatGPT tab + one adapter attempt
  -> success OR clipboard fallback/banner OR terminal failure
  -> delete storage.session payload
```

## State machine and one-time claim

```text
idle
  └─ user context-menu event
      ├─ preview required ──> awaitingConsent
      └─ current consent + permission bundle present ──> queued
awaitingConsent
  ├─ approve + all permissions present ──> queued
  └─ deny / permission missing / consent tab closed / expired ──> terminal(delete)
queued
  ├─ consent/permission revoked ──> terminal(delete)
  ├─ expired / tab closed ──> terminal(delete)
  └─ one claim (claimId) ──> injecting
injecting
  ├─ adapter success ──> terminal(delete)
  ├─ DOM/login/timeout failure ──> fallback ──> terminal(delete)
  ├─ clipboard failure ──> banner/error ──> terminal(delete)
  └─ target tab closed / service restart ──> terminal(delete or expiry cleanup)
```

`queued` を処理する handler は request ID ごとの処理を同一 Service Worker 内で直列化し、その critical section 内で `state === queued` を確認する。唯一の `claimId` を生成して `injecting` として保存し、再読込で自分の claim を確認してから adapter を呼ぶ。`chrome.storage` は compare-and-swap を提供しないため、state の read/write だけで排他を保証したとみなさない。すでに `injecting` または終端状態の payload は無視する。Service Worker 再起動時に `injecting` が残っていても自動再試行せず、tab close または expiry で削除する。

初回 preview には URL と selection の原文ではなく、実際に送信対象となる正規化・上限検査後の fixed prompt を正確に表示する。preview 中の Service Worker 停止に備えて `awaitingConsent` を `storage.session` に保持し、同意画面を閉じた場合も tab close listener で削除する。許可要求後は `chrome.permissions.contains()` で host、`offscreen`、`clipboardWrite` がすべて揃った場合だけ `queued` へ進める。

タイムアウトは active operation の bounded timeout と `expiresAt` の検査で扱う。`alarms` は使わないため、Service Worker が停止している間の期限切れは、次の relevant event、startup、または settings view で検出した時点で削除する。

## X URL extraction

1. context menu callback から `selectionText`、tab id、current tab URL を受け取る。
2. `activeTab` + `scripting` の範囲で isolated world function を実行する。
3. `Selection.anchorNode`/range に近い `article` を候補にし、その article 内の `a[href]` から status link を収集する。
4. `https://x.com/<user>/status/<id>` または `https://twitter.com/<user>/status/<id>` だけを許可し、選択位置への DOM 距離で一つを選ぶ。
5. query/hash と `/photo/...` など status id より後ろの suffix を除去して返す。
6. 候補がない場合は current page URL を同じ許可 origin に限定して sanitize する。許可 URL にできなければ送信を中止する。

最初の `article` を無条件採用しない。親投稿、対象投稿、返信、引用、おすすめが混在することを前提に、selector と fixture を分離する。取得できない場合の fallback は URL only ではなく、selection text と sanitized current URL がある場合だけ固定 prompt を作る。

## ChatGPT Web adapter

- `chrome.tabs.create` で毎回 `https://chatgpt.com/` を新規に開く。`openInBackground` が false のとき active、true のとき background とする。
- 既存会話 URL、既存 tab、会話履歴、Cookie、auth state を使わない。
- host permission が同意済みであることを確認し、adapter の isolated-world script だけを注入する。
- selector は selector registry に置き、composer の発見、入力、送信の各段階に bounded timeout を持たせる。
- MutationObserver は対象 tab の adapter 内でだけ使い、成功・失敗・timeout のいずれかで disconnect する。DOM mutation を無期限に監視しない。
- 送信ボタンを一度だけ操作し、結果が不明なら成功扱いせず、retry せずに fallback へ進む。
- 未ログイン、DOM 変更、host permission 拒否、tab close、timeout は clipboard fallback と小さな banner で明示する。

この adapter は ChatGPT Web の公式連携ではない。実機で検証できない DOM 変更、規約・審査上の問題、誤送信リスクが見つかった場合は ADR の撤回条件を適用する。

## Failure handling

| Failure | Action | Payload | User feedback |
| --- | --- | --- | --- |
| X URL が不正/unsupported | 送信中止 | delete | settings/status で未対応 URL を表示 |
| selection が空/上限超過 | 送信中止 | delete | 選択し直すよう表示 |
| 初回 consent 拒否/画面 close | 送信しない | delete | 拒否と未送信を表示できる場合だけ表示 |
| ChatGPT host permission 拒否 | ChatGPT adapter を呼ばない | delete | host access が必要と表示 |
| ChatGPT 未ログイン | adapter を一度試行後 fallback | delete after terminal | login が必要、clipboard 成否を banner 表示 |
| DOM selector 不一致/DOM 変更 | retry せず fallback | delete after terminal | 自動入力失敗を banner 表示 |
| timeout/送信結果不明 | retry せず fallback | delete after terminal | 二重送信しない旨と clipboard 成否を表示 |
| target tab close | retry せず終端 | delete | 未完了を表示できる場合だけ表示 |
| offscreen/clipboard failure | 手動貼り付けを案内 | delete | clipboard 失敗を明示 |
| Service Worker restart/expiry | stale payload を処理しない | delete | 次の操作で再実行を要求 |

## Security and privacy constraints

- preview には送信する URL、選択文章、宛先、DOM automation が非公式で壊れ得ること、clipboard fallback が clipboard を変更することを正確に表示する。
- 同意前に ChatGPT host、offscreen、clipboardWrite を要求しない。拒否時に payload を残さない。
- URL は HTTPS と許可 host/status path を検証し、query/hash/credentials を除去する。任意 URL を開かない。
- selection text は untrusted input。`textContent`/structured message を使い、`innerHTML`、`eval`、`new Function`、remote code を使わない。
- ChatGPT へ渡す動的値は URL と選択文章だけ。著者、日時、DOM 全文、Cookie、履歴、auth は渡さない。
- 外部 backend、analytics、telemetry、API key、OpenAI API を使わない。
- selector と ChatGPT adapter を分離し、変更時は fixture、回帰テスト、実機 smoke を更新する。
- `storage.session` の pending と `storage.local` の settings/consent version 以外の保存をしない。

## Acceptance criteria

1. 現行スキャフォールドには変更を加えず、実装 PR では `permissions` と optional permissions の理由が CWS/テストと一致する。
2. X 上の選択で右クリック menu に `ChatGPTで解説する` が一項目だけ現れ、他の入口や preset は作らない。
3. 対象 article に近い status link を採用し、X/Twitter HTTPS、query/hash 除去、unsupported URL 拒否を満たす。
4. 固定 prompt の dynamic data が sanitized URL と selection text だけで、untrusted data 境界、ファクトチェック要求なし、回答言語指定なしを満たす。
5. 初回 preview が正規化・上限検査後の実送信内容、宛先、リスクを正確に表示し、明示同意ボタンの直接 gesture から optional permissions を要求する。要求後に一式を再確認し、拒否、不足、画面 close では送信せず削除する。
6. 同意後は毎回新規 `chatgpt.com` tab を作り、foreground default / background setting を守り、既存会話を使わない。
7. awaitingConsent→queued→injecting の遷移と request ID ごとの直列化により claim が一度だけで、成功・拒否・失敗・timeout・consent/target tab close・expiry で pending payload が削除される。
8. ChatGPT 未ログイン、DOM 変更、timeout、clipboard failure が自動 retry なしで banner と fallback 結果を明示する。
9. Cookie/auth/API key/backend/analytics/telemetry/remote code と恒久 X host permission を使用しない。
10. DOM fixture、state transition、permission denial、clipboard failure、unpacked manual smoke がすべて記録される。

## Test strategy

- Unit: URL parser/validator、query/hash sanitizer、selection normalization、fixed prompt、permission/consent version。
- DOM fixture: 親投稿・対象投稿・返信・引用・おすすめが混在する article、X/Twitter URL、query/hash、unsupported URL、選択位置の近傍判定。
- Service Worker: awaitingConsent→queued→injecting、同時 dispatch を直列化した一度だけの claim、重複 context menu event、restart/expiry、consent/target tab close、各 terminal cleanup。
- Permission: consent preview の表示、ボタン gesture 内の request、host/offscreen/clipboardWrite の個別拒否、拒否後の再実行。
- Adapter: selector 不一致、MutationObserver bounded、未ログイン、送信結果不明、auto retry 不在、banner 表示。
- Clipboard: offscreen document の作成/close、Clipboard API 成功、permission 拒否、書き込み失敗、失敗 banner。
- Manual unpacked smoke: X からの selection menu、ChatGPT logged-in/logged-out、foreground/background、tab close、再読み込み、同意撤回、clipboard fallback。実際のアカウント・Cookie・個人情報は fixture やログへ残さない。
